Process

https://litlfred.github.io/bootstrap/v0/ns/Process

A Node Instance holding a BPMN process that coordinates Tasks: its Process Nodes, joined by Sequence Flows, sit in lanes that each name a Role.

Defined by https://www.omg.org/spec/BPMN/2.0/#process.

A term of the bootstrap vocabulary (https://litlfred.github.io/bootstrap/v0/ns/; machine-readable: index.jsonld).
